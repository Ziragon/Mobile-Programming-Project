### 1. Получение проекта

```bash
git clone https://github.com/Ziragon/Mobile-Programming-Project.git
cd Mobile-Programming-Project
```

Либо распакуйте архив с проектом.

### 2. Запуск на физическом телефоне

1. На телефоне включите **Режим разработчика** (Настройки → О телефоне → 7 раз нажать «Номер сборки»).
2. Включите **Отладку по USB** (Для разработчиков → Отладка по USB).
3. Подключите телефон кабелем и подтвердите запрос «Разрешить отладку по USB».
4. Выберите телефон в списке устройств и нажмите **Run ▶**.

### 3. Сборка APK из командной строки

```bash
# Linux / macOS
./gradlew assembleDebug

# Windows
gradlew.bat assembleDebug
```

Готовый файл: `app/build/outputs/apk/debug/app-debug.apk`.
Установка на подключённое устройство:

```bash
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

### 4. Виджет с курсом золота

1. Закройте приложение и сделайте долгое нажатие на пустом месте рабочего стола.
2. Выберите **Виджеты** и найдите виджет приложения (шар с курсом золота).
3. Перетащите его на рабочий стол. Курс подгрузится при запуске игры и по нажатию на виджет.

> Если виджет остался от предыдущей сборки и не реагирует, удалите его с рабочего стола и добавьте заново.
